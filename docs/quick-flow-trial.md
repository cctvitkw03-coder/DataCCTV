# ทดลองขั้นตอนสั้น — 1 ตุลาคม 2026

เก็บแบบเดิมที่ Git tag before-quick-flow-2026-10-01 (ef13a22) แล้ว
ข้อกำหนด V2 เดิมคงไว้ การทดลองนี้เป็นการปรับ UX ตามคำขอผู้ใช้

BOT_FLOW_MODE=quick ใช้เฉพาะชุดรูปใหม่ จำโฟลเดอร์ล่าสุดที่ยังใช้ได้และประเภทงาน/ระบบจากงานยืนยันล่าสุดของผู้ส่งคนเดียวกัน ตั้งวันที่วันนี้ตามกรุงเทพฯ ไม่คัดลอกสาขา อุปกรณ์ หรือรายละเอียดจากงานเก่า
หน้าสรุปมีปุ่มแก้แต่ละช่อง ส่งครบแล้วเพื่อตรวจสอบ และยืนยันบันทึกอีกครั้ง
ข้อบังคับข้อมูลเดิมสำหรับ MOUSE_KEYBOARD และการยืนยัน snapshot คงอยู่
มีปุ่มใช้แบบเดิมสำหรับงานที่ยังไม่ยืนยัน
งานเดิมที่เปิดอยู่ไม่เปลี่ยนขั้นตอน

ย้อนกลับทั้งระบบ: ตั้ง BOT_FLOW_MODE=classic ใน Vercel Production แล้ว redeploy งานใหม่จะใช้แบบเดิม งาน quick ที่ค้างอยู่กดใช้แบบเดิมได้
หากต้องย้อนโค้ดทั้งหมด deploy จาก tag ข้างต้น (ไม่จำเป็นต้องย้อนฐานข้อมูล)
